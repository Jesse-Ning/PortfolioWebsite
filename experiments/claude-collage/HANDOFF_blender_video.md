# 交接文档：东京手账视频 · Blender 版

> 给在用户本机（Windows 11，NVIDIA RTX 4060 Ti 8GB，32GB 内存）运行的新 Claude Code 会话阅读。
> 上一个会话在云端容器里完成了 2D 版视频和 Blender 静帧，但云端没有 GPU，所以视频版要在本机用显卡渲染。

## 目标

把已经做好的 **15.6 秒竖屏东京旅行动态手账视频**（`tokyo-journal/tokyo_journal_15s.mp4`）用 **Blender Cycles + GPU（OptiX）** 重新制作成真正 3D 的版本：
- 镜头运动、时间点、卡点都和 2D 版一致；
- 光影达到 Blender 静帧 `tokyo-journal-blender/preview.jpg` 的质量或更好；
- 用户希望可以用 **DaVinci Resolve** 做后期调色。如果 Resolve 的脚本接口不可用，就用 Blender 合成器或 ffmpeg 调色，并给出可以手动输入到 Resolve 的调色参数。

## 已有文件（都在本目录 `experiments/claude-collage/`）

| 路径 | 内容 |
|---|---|
| `tokyo-journal/` | 2D 版：`index.html`（Canvas 动画，所有元素的绘制和编排）、`timeline.json`（拍点）、`mix.py`（混音）、`CREDITS.md`（素材来源）、`assets/`、`fonts/`、成片 mp4 |
| `tokyo-journal/index_tex.html` + `export_tex.mjs` | 把书页上的平面内容（手写字、印章、涂鸦、视频窗口）导出成贴图。需要 Node + Playwright，命令：`node export_tex.mjs`，在 `tokyo-journal/` 的上一级目录里提供服务 |
| `tokyo-journal-blender/scene.py` | **Blender 静帧场景**，可直接复用：弯曲书页、皮革封面、拍立得、胶带、车票、马克笔、杯子、面积灯、45mm 镜头。参数：`device=gpu samples res key view tilt dist fstop exposure out` |
| `tokyo-journal-blender/tex/` | 静帧用的贴图（书页、拍立得、胶带、车票、笔身标签） |

运行静帧：`blender -b -P scene.py -- device=gpu samples=128 res=200 key=36 view=standard`

## 音乐

用户提供的 Suno 曲目 **"Full Band Hit"（mp3）不在仓库里**，需要向用户要文件，放到 `tokyo-journal/` 下，然后把 `mix.py` 顶部的 `MUSIC` 改成那个路径。
- 曲速约 96 BPM，开头 0.093 秒处有一下全乐队重击。
- 剪辑方式：音乐从视频的 0.507 秒开始播，让重击落在 **0.600 秒**；在 **14.369 秒**切掉音乐，把开头那下重击再接上作为收尾，余音到 15.6 秒。
- 响度标准化到 **-13 LUFS**（用户觉得之前版本音量偏小）。

## 实拍视频素材（需要重新下载）

来源和许可见 `tokyo-journal/CREDITS.md`。都来自 Wikimedia Commons，下载转码版即可。注意：缩略图和转码文件要用 `upload.wikimedia.org` 这个域名。
- 涩谷十字路口延时 2019（CC0）：用 0–15.8 秒
- 东京塔夜景 2019-10-29（CC BY 4.0，**发布时需要署名作者 Nesnad**）：用 5.5–14 秒，以 0.62 倍速播放
- 川越线电车驶过站台（CC0）：用 0–5.5 秒

在 Blender 里建议用**图像序列或视频贴图**贴到撕开窗口的平面上。书页贴图需要重新导出一版**不含视频画面**的，窗口位置留空或留一层纸纤维边。

## 建议做法

1. 先确认环境：Blender（4.2 或更高）、ffmpeg、Python（numpy / scipy / soundfile / pyloudnorm）。缺什么，先征得用户同意再安装。
2. 在 `scene.py` 的基础上加关键帧动画：书写效果可以用逐帧更新的贴图序列，或用遮罩显现；物体落下用带回弹的关键帧；撕开效果可以用形态键或缩放遮罩。
3. 先用低分辨率、低采样（如 50%、16 采样）渲染**几帧关键帧**给用户确认，再全量渲染。参考：1080×1920、64 采样 + OptiX 降噪，预计每帧几秒。
4. 渲染出 PNG 序列 → 用 `mix.py` 生成音频 → ffmpeg 合成 → 调色。
5. 用户偏好：
   - 不要"AI 味"和默认值；
   - 每一步讲清楚取舍和局限；
   - 能自己验证的就先验证，做不到的要明说（比如没法听声音）。
