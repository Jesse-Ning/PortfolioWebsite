# 东京旅行动态手账（15.6 秒）

- `index.html`：画面。桌面、笔记本、手写字、贴纸、印章、车票都由代码绘制，撕开的窗口里播放实拍视频。
- 视频帧序列（`clips/`）没有放进仓库，体积太大。按 `CREDITS.md` 下载三段视频后用 ffmpeg 抽帧：
  - 涩谷：0–15.8 秒，960 宽
  - 东京塔：5.5–14 秒，540 宽
  - 新干线：0–5.5 秒，854 宽
  - 帧率都是 30fps，存成 `clips/<名字>/%04d.jpg`
- `timeline.json`：音乐拍点对应到视频时间（重击在 0.6 秒，收尾在 14.37 秒）。
- `mix.py`：用户提供的 Suno 曲目重新剪辑，加纸张和笔的拟音，响度标准化到 -13 LUFS。
